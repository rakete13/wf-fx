WF FX

Bildeffekte per Attribut: Filmkorn, Duotone, Mesh-Gradient, Vignette und weicher Rand. Größtenteils CSS, ohne GSAP, kombinierbar und für CMS-Bilder gemacht. Begleiter zu WF Anim, WF Slider und WF Page Transition.

00

Einbau

Eine Zeile in den Head Code der Site (Site Settings → Custom Code → Head Code), damit beim Laden nichts flackert. Dann data-fx an das Element hängen, bei Bildern an den img-wrapper, nicht ans Bild.

<script src="https://cdn.jsdelivr.net/gh/rakete13/wf-fx@1.0.2/src/wf-fx.min.js"></script>

Mehrere Effekte mit Leerzeichen: data-fx="duotone grain". Bei „Bewegung reduzieren“ stehen animiertes Grain und animierter Mesh still. Hinweise zur Einrichtung: ?wfx-debug an die URL hängen und die Konsole öffnen.
